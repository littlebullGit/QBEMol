# Result Data

These JSON files contain the energies, errors, bootstrap-embedding trajectories,
and provenance used for the manuscript results of H4, H6, F2, and n-butane.

Energies are in hartree (Ha), energy errors are in millihartree (mHa), distances
are in angstrom, and runtimes are in seconds unless a field says otherwise. Each
file records the source artifact paths and SHA-256 digests used to produce it.
